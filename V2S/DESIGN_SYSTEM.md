# V2S Design System

## Colors

| Token | Value | Usage |
|---|---|---|
| Background | `#050C12` | App and player background |
| Surface | `#0E1920` | Cards and panels |
| Surface 2 | `#1B272E` | Controls and secondary cards |
| Surface 3 | `#243138` | Media placeholder/background |
| Orange | `#FF8400` | Active states and primary actions |
| Text | `#F5F7F8` | Primary text |
| Muted | `#A5AEB4` | Metadata and secondary text |
| Divider | `#2F3B42` | Separators and outlines |

## Layout rules

- 8dp base spacing for compact controls.
- 10-14dp rounded card corners.
- 44-48dp touch targets for icon controls.
- Two-column media grid on portrait library screens.
- Compact numbered song rows.
- Orange active bottom navigation icon and label.
- Dark outlined secondary buttons.
- Orange filled primary buttons.

## Reusable components

`V2SUi` owns common surfaces, buttons, text, dividers and thumbnails so screens do not independently invent spacing or colors.
