V2S PREDEFINED LYRICS
======================

Only files bundled in this folder are used by the lyrics feature.
There is no internet lookup and no audio transcription.

Filename:
  normalized-title - normalized-artist.lrc
Example:
  demo-song - v2s.lrc

LRC format:
  [00:00.00] First line
  [00:05.00] Second line

Only add lyrics you are authorized to bundle/distribute.
